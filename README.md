# 📰 NewsApp

A modern News Application built using React that fetches real-time news using APIs and displays them in a clean, responsive UI.

---

## 🚀 Features

- 📰 Top headlines from different categories (Business, Science, Sports, etc.)
- 🌍 Country-based news (US, India, etc.)
- 🔄 Pagination (Next / Previous navigation)
- ⚡ Real-time data fetching using API
- 📱 Fully responsive UI
- 🔗 Click on news to read full article

---

## 🛠️ Tech Stack

- React (Class Components)
- TypeScript
- JavaScript (ES6+)
- Bootstrap
- News API
